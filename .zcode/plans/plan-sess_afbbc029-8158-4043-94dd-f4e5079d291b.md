# Plan aprobado — Identidad landing→app + Frente de calidad/rendimiento

## 0. Regla de identidad (la del login, en toda la app)
- Sesión Frig → identidad Frig completa (cobre + muralla). Ya ocurre vía `applyThemeConfig(null)`.
- Sesión tenant → efectos derivados 100% de sus tokens (`--color-primary`), sin cobre hardcodeado. Cero hex cobre en la app; todo usa `var(--color-primary)`/`color-mix()`, y el plexus se re-tiñe vía `frig:theme-changed`.

## 1. Fondo de datos en la app
Capa `HeroPlexus` fija `-z-10 opacity-35 hidden md:block` en `(app)/layout.tsx`; páginas con raíz opaca → transparentes.

## 2. Sidebar con efecto
Plexus ~0.25 dentro del aside; `.energy-nav` (arco de energía del item activo, color de marca); hover glow; `.flow-line` como separadores.

## 3. Tipografía y tarjetas
`PageHeader` + `h1` dashboard → `font-display`; `.energy-card` (glow+arco al hover, sin fondo propio) en tiles del dashboard.

## 4. Calidad/rendimiento
- Cache de módulo (promise + TTL) para themes públicos; React Query/AbortController en effects de auth.
- Canvas pausado fuera de vista (`document.hidden` + IntersectionObserver).
- Imágenes de branding con dimensiones/eager; limpieza de CSS muerto y warnings.
- `sw.js`: stale-while-revalidate para estáticos, network-first para /api/.

## 5. Docs para Yggdra (backend)
Cache-Control 300s en endpoints públicos, cookie httpOnly para sesión (hoy localStorage), ETag.

## 6. Verificación
tsc + eslint + build; regresión visual; commit + push (deploy FTP).
